Investment thesis

The value is not the chatbot.
It is the relationship history.

01 / MEMORY

It remembers what matters.

People, events, preferences and emotional moments become useful context over time.

02 / STATE

The relationship changes.

Moones tracks relationship state instead of treating every conversation as a fresh session.

03 / PRESENCE

It can reach back.

Proactive messages, voice, images and timing make the experience feel less like a tool.

Problem

Most AI is useful.
Very little feels personal.

COLD START

Sessions feel separate.

The user keeps explaining context again. Useful memory is still shallow in many products.

GENERIC

Persian is often translated, not native.

Tone, jokes, flirting, boundaries and everyday Persian culture are hard to get right with generic assistants.

PASSIVE

AI waits for commands.

Relationships are two-way. A companion that never initiates rarely feels present.

Unit economics

Too early for a fake LTV.
So we show the plan.

PRICE TEST

Start around 250K Toman / month.

Test multiple price points and paid-value bundles. Do not lock pricing before conversion data exists.

COST CONTROL

Route by cost and importance.

Use stronger models where emotion matters; use efficient models for routine jobs, memory utilities and fallback.

MEASURE

CAC, paid conversion, churn, LTV.

The next growth phase must instrument these properly before scaling paid acquisition.

Trust & risk

A relationship product
must protect trust.

PRIVACY

Personal context is sensitive.

Minimize stored data, separate identity from analytics where possible and never sell private conversations.

COMMERCIAL TRUST

Sponsored means disclosed.

Contextual commerce can be useful, but hidden persuasion would damage the core asset: trust.

IRAN ACCESS RISK

Build for unreliable access.

Telegram is useful today, but owned web/PWA and multi-channel delivery reduce platform and connectivity risk.
