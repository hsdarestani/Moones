01 / COLD START

Every session asks again.

Most assistants optimize for task completion. The emotional continuity between sessions is secondary.

02 / GENERIC CONTEXT

Memory is not a relationship.

Knowing facts about a user is different from modeling trust, intimacy, conflict, rhythm and shared history.

03 / PASSIVE AI

The user always knocks first.

Human relationships are reciprocal. An AI that never initiates interaction rarely feels present.
